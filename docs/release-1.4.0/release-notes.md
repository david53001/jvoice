## JVoice 1.4.0

**JVoice now lives in your Dock instead of the menu bar.** The "J" in the top-right menu bar is gone; everything it did is still there:

- **Right-click JVoice's Dock icon** for Start / Stop Dictation, Settings…, Launch at Login, Help & Tours and Check for Updates….
- **Click the Dock icon** to open Settings. Closing the window never quits JVoice — ⌘Q does.
- **JVoice's own menu bar** (when it's in front) has the same items, plus Edit, so copy and paste work in Settings' text boxes.
- **At login JVoice starts quietly** in the Dock, with no window.

⌥Space works exactly as before in any app, and dictating never brings JVoice to the front.

Your settings, custom words, stats, model and permissions are kept.
